# FIRST GAME: Spark series

**Storyline (from the brief):** Spark invents a first game by coding it,
plays it, falls into it and becomes the character, must play every level to
get back to reality, fails, wins after all, and on the win the dream breaks.

**One-line want, per act:**
1. *Play a game.* There is none, so make one.
2. *Get home.* Beat every level; the last one has a door with Spark's room
   in it.
3. *Beat level 3 for real.* The dream taught Spark how.

**Originality:** the character (Spark), the game (levels, hero, spike
ball, spring, platform, door, HUD), the music and every sound are our own.
No existing game or character is referenced.
